# وصف شامل للمنصة (Master Education Platform)

المنصة هي نظام إدارة تعلم (LMS) متطور مخصص للمدرسين الخصوصيين أو مراكز التدريب، مبني بأحدث التقنيات لضمان السرعة والأمان.

## التقنيات المستخدمة (Tech Stack):
- **Frontend:** React 18 + Vite (للسرعة العالية).
- **Styling:** Tailwind CSS (تصميم عصري ومتجاوب).
- **Backend:** Supabase (PostgreSQL + Auth).
- **Animations:** Framer Motion (للحركات الاحترافية).
- **Icons:** Lucide React.
- **Video Player:** Plyr (مشغل فيديوهات احترافي يدعم الحماية من السرقة).

## الوحدات الرئيسية (Modules):
1. **نظام الطلاب:**
   - تسجيل الدخول برقم الهاتف لضمان التفرد.
   - لوحة تحكم تعرض الباقات المشترك بها.
   - محفظة إلكترونية لشراء الدروس.
   - مشغل فيديوهات محمي.

2. **نظام المحتوى:**
   - تقسيم الدروس لأسابيع وباقات.
   - دعم الفيديوهات (YouTube/Vimeo)، ملفات PDF، والاختبارات.

3. **لوحة تحكم الآدمن:**
   - إدارة الطلاب (حظر/تفعيل).
   - إدارة المحفظة والشحن.
   - إنشاء أكواد التفعيل للباقات.
   - رفع المحتوى ومتابعة الإحصائيات.

## المميزات الأمنية:
- حماية الفيديوهات بطبقات شفافة تمنع الضغط اليمين أو التحميل السهل.
- صلاحيات وصول صارمة (RLS) تمنع الطالب من رؤية بيانات غيره.
